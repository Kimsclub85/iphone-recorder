매일 녹음 시간

끝 시각이 시작보다 이르면 다음 날로 넘어가는 걸로 봐. 예: 23:30 → 06:00.

구글 드라이브 자동 업로드

8MB씩 나눠서 올리고, 와이파이가 끊겼다 돌아오면 이어서 올려. 업로드 끝난 파일도 폰 안 사본은 남아있어.

녹음 파일

  • 아직 녹음 없음.

밤새 켜둘 때

  • 충전기 꽂아두기
  • 설정 → 디스플레이 및 밝기 → 자동 잠금 → 안 함
  • 이 탭을 화면에 띄운 채로 두기 (다른 앱 가거나 잠그면 녹음이 멈춤)
  • Safari 주소창 aA → 웹사이트 설정 → 마이크 → 허용
  • 방해 금지 켜두기 (전화가 오면 마이크가 끊길 수 있음)

녹음은 10초마다 폰 안에 저장돼서, 중간에 끊겨도 그때까지는 남아. 파일 앱으로 옮기려면 목록에서 저장 눌러.
